Wake Plan

时间段 + 任务 + 自动延期。把时间先切段，段里放任务；任务超时了，后面没锁定的任务自动往后延。一天打开一次，看到的就是当前时刻该干的那件事。

核心模型

计划、任务、任务实例，三层结构

市面上的日程 App 大多只服务一种场景，要么是纯待办，要么是日历，要么是习惯打卡。真要把「计划」和「日程」放到一起用，得在几个 App 之间来回切。Wake Plan 把两件事合成一层时间轴。

Plan

计划

一条线，比如「考研英语」。独立计时，跟别的计划互不干扰。

Task

任务

计划里的一件具体事。自带起止时间、重复规则、锁定标记。

TaskCompletion

任务实例

任务在某一天的落地记录。PENDING → IN_PROGRESS → COMPLETED / SKIPPED。

自动延期

超时了怎么办

  1. 实际结束时间晚于计划结束时间，超出的分钟数向下取整。
  2. 同一计划里还没开始、没锁定的后续任务整体往后推，推完继续看下一个。
  3. 遇到锁定的任务就停下，它和它后面的任务留在原位。
  4. 延期只在同一个计划内发生，别的计划不受影响。
10:00 背单词 实际 10:40 结束 → 溢出 40 分钟
11:00 做阅读 顺延到 11:40
12:00 复盘 顺延到 12:40
13:00 午休 锁定 · 遇到它停止级联
功能一览

打开一次，该干的都在眼前

底部四个 tab：现在、计划、统计、设置。专注计时从任务卡片进，模板库和桌面组件在设置里。

现在

  • 打开就是当前时刻的聚合视图，多个计划的任务按时间轴叠在一起
  • 24 小时水平时间线，红线是当前时刻，可以往前翻一天、往后翻一天
  • 一键「开始 / 完成」，完成后弹可撤销的 Snackbar，最多排队 5 条
  • 底部弹层快速建任务，默认挂到最近用的那个计划上

计划

  • 计划列表带 10 种预设色，也能自己填 hex，起始日期可选
  • 任务自带起止时间，重复规则支持仅一次、每天、工作日、自定义星期
  • 跨午夜的任务按次日折算，不用手动改日期
  • 冲突以内联色条标在列表里，不弹窗；计划可以归档
  • 内置 3 个模板：标准晨练、标准学习、周末阅读

专注

  • 从任务卡片进全屏计时环，专注、短休、长休三段轮次
  • 前台 Service 跑倒计时，锁屏也留一条常驻通知
  • 一轮结束直接打卡，专注时长落库并计入统计
  • 同一时刻只允许一个任务处于进行中

统计

  • 近 7 天、近 30 天、本月三个窗口切换
  • 每日完成数折线、按计划柱状、完成率、平均延期
  • 专注时长按天、按计划一起算进去
  • 明细可以导出 CSV，带 UTF-8 BOM，Excel 打开不乱码

设置

  • 通知渠道分开配：任务开始、超时、完成、每日回顾、专注计时
  • 每日回顾默认 21:00 推一条当天的完成率
  • 语言跟随系统、中文、English 三选一，切换后立即生效
  • 备份导出导入 JSON，可以选 passphrase 加密（AES-256）
  • 数据保留策略：永久、90 天、1 年，只清终态记录

通知与桌面

  • 桌面 AppWidget 是 4×2 的迷你时间线，打卡后自动刷新
  • 下拉面板的快捷设置 Tile 走同一个入口
  • 开机、改系统时间、改时区之后闹钟会重新排一遍
隐私与安全

三条硬约束

不是「我们承诺不收集」，而是整个 App 里没有任何能收集东西的东西。

硬约束 01

不发任何网络请求

整个 App 不含任何网络库，统计口径全在本机算。

硬约束 02

数据只存在本机，而且加密

本地库用 SQLCipher 4.6.1 加密（AES-256），密钥在 AndroidKeyStore 里生成并包装。

硬约束 03

没有账号，没有后端

没有账号、没有后端、没有第三方 SDK、没有埋点。

数据在自己手里

  • 数据随时能导出成 JSON 或 CSV，也能导入回来换机
  • 通知权限只在引导页申请一次，被拒之后在设置页留了系统设置入口
  • 备份可选 passphrase 加密（AES-256 + PBKDF2）

已知限制

  • 专注计时依赖前台 Service，部分国产 ROM 的后台限制可能让倒计时通知中断
  • 进程被杀之后，正在进行的专注场次不会恢复，重新打开会看到未结算的状态
  • 精确闹钟在部分 ROM 上需要额外授权，已在设置页给出提示
  • v0.6 之前导出的备份里没有 focus_sessions 字段，导入时按空集合处理
从源码构建

JDK 17 + Android SDK 35

需要 Android SDK Platform 35 和 Build-Tools 35.0.0；模拟器 API 26 以上，或者开了 USB 调试的真机。

clone
git clone git@github.com:uwakeme/wake-plan.git
cd wake-plan

local.properties 不在仓库里，第一次要自己写一份，里面指到本机 SDK 路径：sdk.dir=D:\Program Files\Android\Android SDK。

build
./gradlew :app:assembleDebug
./gradlew :app:installDebug
test
./gradlew :app:testDebugUnitTest
./gradlew :app:lintDebug
./gradlew :app:connectedAndroidTest

JVM 单测 326 个用例、56 个测试套件，JUnit 5 + MockK + Turbine，不依赖 Robolectric。数据库迁移测试放在 androidTest，用 Room 的 MigrationTestHelper 跑，会连 SQLCipher 加密路径一起验。提交前单测全绿、lint 0 error 是硬门槛。

依赖和 Gradle wrapper 都走国内镜像：settings.gradle.kts 配了阿里云 maven 三件套，wrapper 指向国内 gradle 镜像，第一次 sync 大概 2 到 5 分钟。
