## 0. 决策背景

v0.4.1 正确性修复版收口后，存量待办分两层：**v0.5 = 体验与统计完善**（PRD US-10 收尾的每日回顾、US-12 扩展的按月统计、CSV 导出、撤销栈，外加审查新增的数据保留策略）；**v0.6 = 番茄钟·绑任务专注页**（需要 focus_sessions 新表，schema v5，与 task_completions 复合索引搭一批迁移）。

本会话拍板的四项决策：

1. 一份文档覆盖 v0.5 + v0.6（照 16 号文档先例）；番茄钟只到骨架，v0.5 收口后按内测反馈细化
2. 数据保留清理进 v0.5，**默认永久**——只有用户主动改设置才清理，且只清终态（COMPLETED/SKIPPED）超龄行
3. 撤销栈形态 = **Snackbar 队列**（栈深 5，逐条出队），Today 页不加常驻 UI
4. v0.4.0 / v0.4.1 的 tag 与 Release **继续搁置**（发布待办见 17 号文档第 5 节）

## 8. 验收口径

- 每个 behavior 同步加测试（JUnit5 + MockK，参考同包已有 `*Test.kt`）；每次提交前单测全绿 + `:app:lintDebug` 0 error
- 阶段各事项 commit 后 push main；v0.5 收口时 `assembleDebug` + emulator 冒烟
- v0.6 动 schema 前单独 commit（entity + DAO + migration + androidTest），再上功能——v0.4.1 修复的迁移纪律不能回退
