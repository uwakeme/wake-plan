## 4. 已知技术债（记录在案，暂不处理）

- **统计口径近似**：已删除计划的历史完成在分子但不在分母（分母按现存任务定义推导），极端情况完成率 > 1，UI 层消费时需 coerce 到 1。
- **DST 静默切换**：部分时区夏令时切换不发 TIMEZONE_CHANGED，已挂闹钟可能错 1 小时，等下次打开 App 重排自愈。低频，暂不处理。
- **BootReceiver goAsync 无超时**：慢设备上 SQLCipher 首开 + 全表查询极端情况可能超时被杀（有系统重试兜底）。
- **闹钟 id hashCode 碰撞**：requestCode/notification id 基于 completionId.hashCode()，跨段偏移已缓解，理论碰撞会互相覆盖。数据量小，风险可忽略。
- **seed 时机**：内置模板 seed 在 App.onCreate 异步跑，极快解锁首帧可能闪一下空模板列表（幂等标记已保证不重复 seed）。
